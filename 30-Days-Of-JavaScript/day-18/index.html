Day 18

Promises, Async/Await & Fetch API

👉 Hướng dẫn: Nhấn phím F12 (hoặc chuột phải chọn Inspect / Kiểm tra) và chuyển sang tab Console để xem toàn bộ kết quả phân tích dữ liệu API và bảng thống kê (console.table).

📁 Nội dung các tệp JavaScript:

  • level1.js: Gọi Fetch API RestCountries (https://restcountries.com/v2/all) sử dụng cả hai cách tiếp cận: Promise (.then().catch()) và hiện đại (async/await). Trích xuất name, capital, languages, population, area.
  • level2.js: Gọi Fetch API TheCatAPI (https://api.thecatapi.com/v1/breeds), trích xuất mảng tên catNames và tính trọng lượng trung bình loài mèo theo đơn vị kg.
  • level3.js:
    1. Tính trung bình trọng lượng mèo theo đơn vị metric (kg).
    2. Tìm 10 quốc gia có diện tích lớn nhất thế giới sắp xếp theo bảng.
    3. Đếm tổng số ngôn ngữ chính thức độc nhất trên toàn thế giới bằng cấu trúc dữ liệu Set.

💡 Ghi chú kỹ thuật về API bên thứ ba (Third-party APIs):

Các API công cộng bên ngoài (như RestCountries v2 & TheCatAPI) có thể bị thay đổi chính sách (đổi version, yêu cầu API key cá nhân hoặc chặn CORS). Toàn bộ mã nguồn đã được thiết kế chuẩn cấp doanh nghiệp với khối try...catch bắt lỗi và bộ Fallback Data dự phòng tự động kích hoạt, đảm bảo chương trình luôn chạy mượt mà 100% không bị ngắt quãng.
